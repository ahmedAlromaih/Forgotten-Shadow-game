# Forgotten Shadow

Design and production repository for a 2.5D action roguelite built around teleportation, elemental boss weaknesses, and the cost of losing one's identity. Gameplay is constrained to a side-view plane while reusable 3D characters, modular environments, lighting, and VFX reduce the volume of hand-drawn art.

## Vertical-slice premise

The player, already transformed into a shadow, fights through three boss rooms and absorbs each guardian's magic. In the throne room, the immortal Shadow King attacks continuously. The player must evade his magical shots, break three seals, reach the imprisoned sorcerer, and kill him to reverse the King's immortality ritual.

## Proposed stack

- Unity 6 LTS with Universal Render Pipeline
- C#
- Git and GitHub
- Blender for modular 3D assets; Krita or Photoshop for textures and UI
- Reaper or Audacity for audio editing

## Project status

Pre-production. The current target is a single 15–20 minute boss-rush vertical slice.
